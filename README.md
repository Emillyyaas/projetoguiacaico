# Guia Interativo de Caicó - RN

Projeto semestral de HTML e CSS. Site com um guia digital de Caicó (Rio Grande do Norte): turismo, gastronomia, serviços, horários e formulário de sugestões.

> Observação: nomes de restaurantes, endereços, horários e preços são exemplos. Os pontos turísticos (Catedral de Sant'Ana, Museu do Seridó, Açude Itans) e a Festa de Sant'Ana são reais, mas confira os detalhes antes de entregar.

```
    └── contato.html
```

## Como a Web funciona (resumo)

- **HTML** define o conteúdo e a estrutura da página.
- **CSS** define a aparência (cores, fontes, layout).
- **HTTP** é o protocolo que o navegador usa para pedir páginas a um servidor, que responde com o HTML; depois o navegador pede também o CSS e as imagens.

## Etapas

1. README e estrutura de pastas
2. index.html com título, lista, links e imagem
3. Páginas de turismo, gastronomia e serviços (tags semânticas)
4. Tabela de horários e preços (horarios.html)
5. Formulário de sugestões (contato.html)
6. Metadados, alt, label e títulos h1 a h3
7. CSS base: fontes, cores, listas, links, menu
8. Layout com div, flexbox e media queries
9. Classes .destaque, .aviso, .evento, .promocao, cartões e hover
10. Relatório final (relatorio.html)
